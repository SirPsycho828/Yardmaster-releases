## Overview

This repository holds only the published builds of Yardmaster. It contains no source code.
The app checks this repository for new versions and updates itself.

## Install

1. Open the [latest release](../../releases/latest).
2. Download the file for your computer:

| Computer | File |
| --- | --- |
| Mac with Apple Silicon (M1 or newer) | `Yardmaster-<version>-arm64.dmg` |
| Mac with an Intel chip | `Yardmaster-<version>.dmg` |
| Linux | `Yardmaster-<version>.AppImage` |

3. On a Mac, open the `.dmg` and drag **Yardmaster** into **Applications**.

The Mac app is signed by Bold Arrow Group LLC and notarized by Apple, so it opens without a warning.

## Access

Signing in requires an approved account. If you see "Account not authorized", use
**Request access** in the app and wait for approval.

## Updates

Installed copies update automatically. There is no need to download a new version by hand.
